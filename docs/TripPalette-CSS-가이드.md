# TripPalette CSS 디자인 가이드

이 문서는 TripPalette의 모든 화면에서 공통으로 사용하는 색상, 레이아웃, 컴포넌트와 반응형 기준을 정의합니다. 새 페이지를 만들거나 기존 CSS를 수정하기 전에 이 문서를 우선 확인합니다.

## 1. 디자인 방향

TripPalette 로고는 사계절의 자연을 표현하는 딥그린, 세이지, 블루그레이, 머스타드, 오렌지와 베이지로 구성됩니다.

- 딥그린을 핵심 브랜드 색상으로 사용합니다.
- 세이지와 베이지는 배경과 보조 영역에 사용합니다.
- 머스타드와 오렌지는 별점, 배지, 선택 상태 등 작은 영역에만 사용합니다.
- 한 화면에서 강조색을 동시에 과도하게 사용하지 않습니다.
- 전체 비율은 중립·연한 배경 70%, 딥그린 계열 20%, 머스타드·오렌지 10%를 권장합니다.

## 2. 공통 색상 토큰

색상을 페이지 CSS에 직접 반복해서 작성하지 않고 `app/static/css/style.css`의 변수를 사용합니다.

```css
:root {
    --color-primary: #1e403b;
    --color-primary-dark: #395b4f;
    --color-secondary: #587e7e;
    --color-sage: #90ac9b;
    --color-accent: #edaa44;
    --color-accent-strong: #cd6238;
    --color-brick: #a64427;

    --color-text: #1e403b;
    --color-muted: #6b7280;
    --color-border: #dcddd3;
    --color-surface: #ffffff;
    --color-background: #f1f5f2;
    --color-background-warm: #f7f4ec;
    --color-beige: #e3d2b1;
}
```

### 색상별 역할

| 토큰 | 역할 | 사용 예시 |
|---|---|---|
| `--color-primary` | 핵심 브랜드색 | 주요 버튼, 제목, Footer |
| `--color-primary-dark` | 보조 딥그린 | Hover, 카드 제목, 보조 버튼 |
| `--color-secondary` | 정보색 | 링크, 아이콘, 메타 정보 |
| `--color-sage` | 부드러운 선택색 | 필터 칩, 태그, 보조 배경 |
| `--color-accent` | 밝은 강조색 | 별점, 선택 상태 |
| `--color-accent-strong` | 강한 강조색 | 중요 배지, 상태 표시 |
| `--color-brick` | 짙은 포인트색 | 강조 Hover, 오류 제목 |
| `--color-background` | 기본 연한 배경 | 페이지, Empty State |
| `--color-background-warm` | 따뜻한 배경 | 섹션 구분, CTA 보조 영역 |

세이지와 머스타드 위에는 흰색 글자 대신 `--color-text`를 사용합니다. 머스타드와 오렌지는 넓은 배경보다 작은 포인트에 사용합니다.

## 3. 레이아웃 기준

- 데스크톱 콘텐츠 최대 폭: `1200px`
- 데스크톱 좌우 여백: 최소 `32px`
- 태블릿 좌우 여백: `32px`
- 모바일 좌우 여백: `20px`
- 카드 간격: 기본 `24px`
- 목록: 데스크톱 3열, 태블릿 2열, 모바일 1열
- Header, 본문, Footer의 콘텐츠 시작선을 맞춥니다.
- 배경과 히어로 이미지는 전체 폭을 사용할 수 있지만 텍스트와 조작 UI는 공통 컨테이너에 정렬합니다.

## 4. 공통 컴포넌트

### 버튼

- 주요 버튼: 딥그린 배경과 흰색 글자
- 주요 버튼 Hover: 서브 딥그린
- 보조 버튼: 흰색 배경, 딥그린 테두리와 글자
- 버튼 모서리: 기본 `9px`, 필터 칩이나 원형 UI는 `999px`
- 버튼 텍스트가 없는 아이콘 버튼에는 반드시 `aria-label`을 제공합니다.

### 카드

- 배경: `--color-surface`
- 테두리: `1px solid var(--color-border)`
- 모서리: `14px`~`16px`
- 그림자: `--shadow-card`
- 이미지가 없으면 연한 세이지 배경의 Placeholder를 표시합니다.
- 카드 전체가 링크이면 내부에 중복 링크를 만들지 않습니다.

### 입력창과 필터

- 흰색 또는 반투명 배경과 공통 테두리색을 사용합니다.
- Focus 상태는 딥그린 테두리와 Focus Ring으로 표시합니다.
- Label을 생략하지 않습니다.
- 선택된 필터는 연한 세이지 배경과 딥그린 글자로 표시합니다.

### 상태색

- 별점: 머스타드
- 일반 정보: 블루그레이
- 중요 배지: 오렌지
- 오류: 브릭 오렌지 계열
- 색상만으로 상태를 전달하지 않고 텍스트나 아이콘을 함께 제공합니다.

## 5. 페이지별 적용

### Header와 Footer

- Header는 흰색을 유지하여 다색 로고가 명확히 보이게 합니다.
- 로그인은 Outline, 회원가입은 딥그린 Filled 버튼을 사용합니다.
- Footer는 딥그린 배경과 연한 베이지·세이지 계열 글자를 사용합니다.

### 메인 페이지

- 히어로 위 텍스트는 흰색을 사용합니다.
- 이미지 Overlay는 딥그린 계열 반투명 Gradient를 사용합니다.
- 인기 여행지 태그는 세이지 배경과 딥그린 글자를 사용합니다.
- 추천 CTA는 딥그린과 블루그레이 Gradient를 사용합니다.

### 여행지·숙소 목록

- 목록 배경은 연한 세이지 또는 웜 베이지를 사용합니다.
- 카드 제목은 딥그린, 상세 링크는 블루그레이를 사용합니다.
- 평점 별은 머스타드, 지역·인원 태그는 세이지를 사용합니다.
- 가격은 딥그린 또는 핵심 브랜드색으로 강조합니다.

## 6. 접근성과 반응형

- 일반 본문은 배경과 최소 `4.5:1` 명도 대비를 확보합니다.
- 흰색 글자는 딥그린처럼 충분히 어두운 배경에서만 사용합니다.
- 키보드 Focus 표시를 제거하지 않습니다.
- 의미 있는 이미지에는 구체적인 `alt`를 제공합니다.
- `900px` 이하에서는 목록을 2열로 전환합니다.
- `620px` 이하에서는 목록을 1열로 전환합니다.
- 최소 `375px` 화면에서 가로 스크롤이 발생하지 않아야 합니다.
- `prefers-reduced-motion` 환경에서는 불필요한 애니메이션을 줄입니다.

## 7. 파일 역할

| 파일 | 역할 |
|---|---|
| `app/static/css/style.css` | 색상 토큰, 공통 레이아웃, Header, Footer, 버튼 |
| `app/static/css/main.css` | 메인 페이지와 히어로 |
| `app/static/css/destination.css` | 여행지 목록·상세 |
| `app/static/css/accommodation.css` | 숙소 목록·상세 |

- 페이지 전용 스타일을 `style.css`에 넣지 않습니다.
- 공통 색상은 페이지 CSS에 새 HEX 값으로 복제하지 않습니다.
- 공통 토큰 변경은 팀장 확인 후 반영합니다.
- CDN UI 프레임워크를 임의로 추가하지 않습니다.
