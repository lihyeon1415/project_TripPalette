# 작업자 3 — 숙소 목록·상세 페이지 고도화

작업 브랜치: `feature/accommodation-ui`

PR 대상: `develop`

상태: 미착수

## 목표

이미 SQLAlchemy 데이터가 연결된 숙소 목록과 상세 페이지를 TripPalette의 메인·여행지 디자인과 통일하고, Phase 5 예약 기능이 연결될 자리를 준비합니다. 이번 작업에서는 예약·결제를 구현하지 않습니다.

## 담당 파일

```text
app/templates/accommodation/list.html
app/templates/accommodation/detail.html
app/static/css/accommodation.css
```

## 기존 URL 계약

| 기능 | Method | URL |
|---|---|---|
| 전체 숙소 목록 | GET | `/accommodations` |
| 여행지 주변 숙소 | GET | `/destinations/<id>/accommodations` |
| 숙소 상세 | GET | `/accommodations/<id>` |

## Template 변수 계약

### `list.html`

```text
destination       특정 여행지에서 진입하면 Destination, 전체 목록이면 None
accommodations    숙소 목록
```

### `detail.html`

```text
accommodation     숙소 상세와 연결된 destination 관계
```

사용 가능한 숙소 필드:

```text
name
address
description
price_per_night
capacity
rating
image_url
destination
```

Python View와 변수명은 변경하지 않습니다.

## 숙소 목록 화면

- 특정 여행지 진입과 전체 숙소 진입의 제목·안내 문구를 구분합니다.
- 특정 여행지 목록에서는 여행지 상세로 돌아가는 링크를 제공합니다.
- 상단에 숙소 개수를 표시합니다.
- 숙소 카드는 이미지, 숙소명, 주소, 평점, 최대 인원, 1박 가격을 표시합니다.
- 카드 전체 또는 명확한 상세 버튼으로 숙소 상세에 이동합니다.
- 숙소가 없으면 여행지 둘러보기로 이어지는 Empty State를 제공합니다.
- 현재 데이터에 없는 숙소 유형이나 편의시설은 임의로 표시하지 않습니다.

## 숙소 상세 화면

- 대표 이미지와 숙소 핵심 정보를 상단에 배치합니다.
- 숙소명, 주소, 1박 가격, 최대 인원, 평점을 명확하게 구분합니다.
- 설명이 없으면 `등록된 숙소 소개가 없습니다.`를 표시합니다.
- 연결 여행지가 있으면 여행지 상세와 주변 숙소 목록으로 돌아갈 수 있어야 합니다.
- Phase 5 예약 영역은 시각적으로 준비하되 실제 제출 Form이나 결제 이동은 만들지 않습니다.
- 예약 버튼이 필요하면 `aria-disabled="true"`와 `예약 기능 준비 중` 문구로 비활성 상태를 명확하게 표시합니다.

## 이미지 정책

- `image_url`이 있으면 해당 이미지를 사용합니다.
- 이미지가 없거나 로딩에 실패하면 중립적인 숙소 Placeholder를 표시합니다.
- 출처가 불명확한 외부 숙소 사진을 새로 하드코딩하지 않습니다.
- 숙소 유형 필드가 모델에 없으므로 호텔·리조트·펜션 등으로 임의 분류하지 않습니다.
- 목록 이미지는 `loading="lazy"`를 사용하고 상세의 첫 이미지는 즉시 표시합니다.

## 반응형·접근성

- 최대 콘텐츠 폭은 1200px입니다.
- 목록은 데스크톱 3열, 태블릿 2열, 모바일 1열을 기본으로 합니다.
- 375px에서 가로 스크롤이 없어야 합니다.
- 가격 단위와 최대 인원을 화면 낭독기로 이해할 수 있게 작성합니다.
- 평점이 없을 때 별점 `0`이 아니라 `평점 정보 없음`을 표시합니다.
- 이미지 `alt`, Heading 순서, Focus 상태를 유지합니다.
- 카드 Hover가 주변 Layout을 밀지 않아야 합니다.

## 확인 시나리오

1. `/accommodations`에서 전체 숙소가 표시됩니다.
2. 여행지 상세에서 주변 숙소 목록으로 이동합니다.
3. 주변 숙소 목록에 해당 여행지 숙소만 표시됩니다.
4. 숙소 카드에서 상세로 이동합니다.
5. 상세에서 연결 여행지로 돌아갑니다.
6. 이미지·설명·평점이 없어도 화면이 깨지지 않습니다.
7. 숙소가 없는 여행지에 Empty State가 표시됩니다.

## 금지사항

- 여행지 상세 또는 추천 페이지 파일 수정

## 완료 기준

전체 숙소 및 여행지별 숙소 목록에서 실제 데이터가 정확히 표시되고 상세 페이지로 이어지며, 빈 데이터·이미지 실패·모바일 환경에서도 화면이 안정적으로 동작합니다.
