## 사진 기준

- 실제 숙소와 일치하는 대표 사진 1장
- 가로형, 최소 1200×800 권장
- JPG 또는 WebP, 가능하면 500KB 이하
- 워터마크, 가격표, 홍보 문구가 크게 박힌 사진 제외
- 사진을 확인할 수 없으면 임의의 비슷한 숙소 사진으로 대체하지 않고 `pending`으로 보고

## 저장 경로

```text
app/static/img/accommodation/{여행지명}/{숙소명}/01.jpg
```

## 매핑 산출물

다음 파일만 작성한다.

```text
docs/phase4/2026-09-30-accommodation-inline/photo-map-a.json
```

레코드 형식:

```json
{
  "destination_name": "거제",
  "accommodation_name": "숙소 이름",
  "image_url": "/static/img/accommodation/거제/숙소 이름/01.jpg",
  "source_url": "원본 출처 URL",
  "status": "ready"
}
```

`app/data/accommodations.json`은 수정하지 않는다.

## 완료 조건

- 신규 대상 35개 전부 처리 또는 미확보 항목을 `pending`으로 명시
- 모든 `ready` 경로에 실제 파일 존재
- 숙소명과 사진 대상이 일치
- 출처 URL 누락 없음
- 담당 지역 밖 파일 수정 없음
